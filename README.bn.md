**বিশেষ:** [Aubergine](https://github.com/thirstyeggplant/aubergine) - আপনার ব্রাউজারে একটি ক্যানভাসে আপনার সব টার্মিনাল। একসাথে পাশাপাশি কয়েকটি কোডিং এজেন্ট (Claude Code, Codex, Cursor এবং সাধারণ শেল) চালান এবং এক নজরে দেখুন কোনটি আপনার অপেক্ষায় আছে, প্রতিটি কোন ধাপে আছে এবং প্রতিটি আপনার জন্য কী লিখেছে। এটি আপনার নিজের কম্পিউটারে চলে।

ফ্রন্ট-এন্ড, মিডল-টিয়ার, ব্যাক-এন্ড, অ্যালগরিদম এবং continuous delivery শিখুন। টিপস: আপনি যদি
Stack Overflow-এ যেকোনো ট্যাগে ক্লিক করে info ট্যাবে যান, সেখানে সেই ট্যাগ সম্পর্কিত রিসোর্স পাবেন।
