Daftar pilihan untuk menjadi Full Stack

Unggulan: Aubergine - Semua terminal Anda di satu kanvas di browser. Jalankan beberapa agen coding (Claude Code, Codex, Cursor, dan shell biasa) berdampingan dan lihat sekilas mana yang sedang menunggu Anda, di langkah mana masing-masing berada, dan apa yang telah ditulis masing-masing untuk Anda. Berjalan di komputer Anda sendiri.

Pelajari front-end, lapisan tengah, back-end, algoritme, dan continuous delivery. Tips: jika Anda membuka Stack Overflow, mengeklik tag apa pun, lalu membuka tab info, Anda akan menemukan sumber tentang tag tersebut.
